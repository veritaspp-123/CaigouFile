# 采购实施方案编制工具（内网可部署）

一个纯静态 HTML 工具：提供 6 章节录入框架，支持第 1 章结构化字段组，并可统一生成与导出 Word 文档。

## 本轮优化内容

- **管理员配置入口隐藏化**：
  - “模板映射与上下文编辑”不再默认暴露给普通用户；
  - 通过“管理员：模板映射管理”按钮进入，并有二次确认提醒“请勿随意修改”。
- **章节暂存能力**：
  - 每个章节新增“暂存本章”按钮；
  - 新增“暂存全部章节”按钮；
  - 使用浏览器本地存储自动加载历史暂存内容。
- **表单可读性增强**：
  - 强化字段标签（高亮底色、加粗、必填标记）；
  - 录入区与章节容器分层展示，避免“填写项与被填写项混在一起”的视觉问题。

## 功能特性

- 6 章节分章录入与整文合成。
- 第 1 章支持评审文件字段组新增/删除。
- 管理员可配置模板正文、字段组条目模板和映射 JSON。
- 支持预览、复制、导出 Word（.doc 兼容）。
- 纯前端离线运行，无后端依赖。

## 使用方法

1. 打开 `index.html`。
2. 按章节录入并点击“暂存第X章”保存草稿。
3. 完成后点击“生成文档”并导出 Word。
4. 仅管理员在必要时通过“管理员：模板映射管理”调整模板和映射。

## 打包部署

- 将 `index.html` 和 `README.md` 打包上传内网平台即可。
